# 会话-16：从传记播放器改造为互动视觉小说

## 用户批准的计划（会话-17 执行）

### 目标与范围

- 将“事件摘要＋一次选择”改造成“进入场景、与人物交谈、作出行动、承担后果”的互动小说。
- 扩写童年至1999年的整个早期篇，单轮阅读与决策目标45～90分钟。
- 半写实年代背景、人物立绘、不同表情、逐句对白；人生抉择与人物关系优先。
- 手动为主入口，全自动为次要观众模式；不迁移 Node 20，不增加联网 AI 或配音。

### 剧情与选择

- 六章：少年、加拿大、大学、人生岔路、事业考验、1999年终章。
- 42个主线及分支场景、6个条件插曲；典型单轮24～32场、1.2万～1.8万字。时长须试玩核验，不以自动播放计时替代。
- 每场有地点、动机、冲突、行动机会；对白、独白和旁白交替，时间只在场景或章节收束推进。
- 态度、行动和人生决定影响对白、关系、机会、路线；至少6条跨场景承诺反馈链，汇合不清除记忆。
- 科研、创业、工程师、游戏事业、独立人生五类结局，关系和承诺产生不同尾声。
- 马斯克、梅耶、金巴尔真实身份；同学、同事、招聘者、投资人、发行人为明确标注的原创配角。历史节点核对史料，创作对白不能冒充原话。

### 人物素材与演出

- imagegen真实独立位图，胶片颗粒、低饱和暖光与深青阴影。
- 主角少年、青年、成年三个母版各6表情，其余7人各4表情，共46张透明半身立绘。
- 同角色先母版再参考编辑，保持面容、服装、发型和位置；禁止重复图片充当表情。
- 8背景：少年卧室、机场、校园、宿舍、招聘大厅、创业办公室、会议室、城市公寓；适合的背景复用，卧室新做无人版。
- 最多两角色，说话者高亮、节点切换表情；移动端优先说话者，不遮正文。
- 支持说话者、旁白、内心独白、逐句推进、只读回看；点击/空格/回车先补全再推进；可关闭打字及动画。
- 手动选择停等；自动逐句阅读，保留倍速、暂停、接管与后台停止；按场景预加载素材。

### 引擎与存档

- 纯函数引擎内增加旁白、对白、选择、条件分支、结束节点和稳定ID。
- choose处理当前合法选择，advance推进对白或收束场景；手动/自动/工具接口同入口。
- 人物信任、承诺状态、记忆进入条件；关系档案自然语言反馈。
- 同种子同选择可复现，阅读速度/表情/回看不能改结果，效果仅结算一次。
- 新版独立parallel-lives:v2:存档保存节点位置、结果、关系、承诺；v1原样保留可备份，不迁移、不删除、不提供旧版续玩。读档暂停。

### 实施与验收

- 先少年章闭环，再完成整个早期篇；不是仅交付少年章。
- 校验断链、不可达、循环、缺分支出口、人物/表情/背景引用。
- 测试关系、承诺、汇合、复现、1000种子、5结局；测试各节点存档、不重复结算、旧档保留、播放中断。
- 用户明确授权真实浏览器试玩：少年章完整、各路线代表场景、结局、桌面/手机、键盘、大字、全部表情。
- 两套构建与资源路径校验；时长不足补有效剧情。
- 更新plan、AGENTS整体认知、秒级workflow完整diff及索引。
- 仅本地交验，不自动提交/推送/发布，原Sites不变。
