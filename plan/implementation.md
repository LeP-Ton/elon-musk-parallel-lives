## 验证与已知边界
- `pnpm test`：26 项测试通过，其中完整路线测试运行 30 个种子 × 8 种策略。
- `pnpm validate:content`：核心与独立测试包全部通过，包含资产文件检查。
- `npm run build`：TypeScript 与生产静态导出成功，输出 `dist/client`。
- 本地服务器已实际返回 HTTP 200，并将预览发送至应用面板。本轮未执行浏览器点击、截图或视觉回归测试。
- WebMCP（网页结构化交互提案）做了模拟上下文合同测试；当前未在支持该提案的真实浏览器中验收，不宣称浏览器集成已验证。
- 依赖修复后，审计仍报告 Cloudflare 开发工具链中 sharp/libheif 的 4 条传递风险；游戏构建不启用 Cloudflare 插件，发布物是纯静态文件，不包含该工具链。未采用审计建议的破坏性降级。
- 历史、人格和金钱变化属于受约束的游戏建模；未声称概率有真实统计依据。

## 范围边界
本轮交付为要求第八十三节指定的 Vertical Slice，非 1971～2002 完整 V1。Slice 结局允许延伸到 1999 年；PayPal、SpaceX、Tesla、AI 作为后续内容包，不伪装为已实现。人物数值是游戏建模，不是心理学诊断。

## 验收重点
- 同种子和同选择可复现；视觉随机不影响结果。
- Netscape 工程师可回到 Zip2 类似历史路线，历史偏离不会因此抹除。
- 创业失败后进入工程师路线，长期稳定工作累积自主冲突并解锁新创业机会。
- 新测试内容包只需注册即可在符合条件的旧状态触发，移除后核心内容正常。
- 存档只保存 ID、状态、历史、随机序号和版本；损坏及不兼容存档明确提示。
- 校验器覆盖引用、条件、权重、来源、标签、资产及包依赖；测试覆盖主要分支。
