# 会话-21：补齐人物表情并恢复透明背景

## 背景与授权
- 会话-18暴露了部分立绘缺失，导致 `/assets/novel/characters/claire-worried.png` 等资源在某些场景空白。
- 用户授权“仅修复透明蒙版”，不再允许用 neutral 图替代不同表情。

## 关键结果
- 全量补齐为 46 张立绘资源（10 张 neutral 母版 + 36 张新增/恢复立绘）。
- 21 张表情由 imagegen 生成，15 张既有 RGB 表情保持原稿并补齐 alpha。
- 开发脚本 `scripts/restore_portrait_alpha.py` 与测试 `tests/test_restore_portrait_alpha.py` 验证：
  - 仅改 alpha 不改 RGB
  - 不允许覆盖源文件
  - 尺寸与透明母版校验一致
  - 边缘清理参数生效且不破坏主体白色区
  - 7 个测试项通过

## 验收
- `npm run validate:content` 与 70 项现有测试通过（含 1,000 种子）。
- 两套静态构建通过：`npm run build` 与 `npm run build:pages`。
- 本地资源检查覆盖 46 个 PNG，HTTP 与 SHA 都一致。
- `claire-worried.png` 的缺失问题已关闭。

## 风险与边界
- 已完成素材生产与透明修复；剩余工作是剧情体验验收（手工通关、时长与多结局反馈），非素材层缺陷。
- 本文不再包含完整二进制补丁清单文本，仅保留关键行为和验证点。
