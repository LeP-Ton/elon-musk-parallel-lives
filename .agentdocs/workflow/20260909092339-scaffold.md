# 会话-1：通用组件脚手架差异

## 背景与目标
- 会话-1 在空目录上快速建立可开发的页面骨架。
- 目标是尽快形成可复用的基础交互层，减少后续玩法开发的重复工作。

## 关键变更
- 引入项目级通用 UI 组件集合（Shadcn/Base 风格），覆盖按钮、对话框、表单控件、布局与提示类组件。
- 新增通用 hooks 与环境适配层（如移动端判断）。
- 补齐 `lib/utils.ts` 通用工具函数，支持组件样式与状态统一。
- 页面入口/基础布局与可访问行为在本阶段完成标准化。

## 架构影响
- 该批次主要属于底层脚手架，不承载业务规则。
- 视觉小说和叙事规则后续改动建议沿当前组件接口扩展，避免直接替换底层组件实现。

## 验收与边界
- 通过与后续会话的联合构建验证后进入可用状态。
- 不再保留逐文件全量补丁正文；如需精确差异请查 commit 或后续会话文档中的“关联文件”记录。
- 风险主要在于第三方脚手架版本演进，升级时要同步验证 class 名与行为差异。
