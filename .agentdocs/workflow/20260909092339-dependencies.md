## 背景与目标
- 在空目录初始化稳定的 React + TypeScript + Vite/Vinext 开发链路。
- 以锁文件为准控制版本，降低后续构建漂移风险。

## 关键变更
- 配置仓库级忽略和版本管理文件（如 `.gitignore`）。
- 固化平台与部署相关配置（含 `.openai/hosting.json` 等）。

- 完成 `package.json` 与 `package-lock.json` 的版本收敛，保证构建脚本和依赖树可复现。
