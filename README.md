# 马斯克传：平行人生

一款以真实历史为骨架、让玩家与人物惯性共同改写人生的互动小说。当前为第一阶段可玩切片：15 个核心事件、3 个条件插曲、5 种阶段结局，另有独立扩展验收包。

## 本地运行

需要 Node.js >=22.13（已在 Node.js 24 验证）。项目保留 Sites 脚手架的 npm 锁文件，可使用 npm 或 pnpm 执行脚本。

```bash
npm ci
npm run dev -- --port 5187
```

访问终端给出的本机地址。普通游玩只需点击选择与“翻开下一页”；数字键 1—4 选择，Enter 继续。页面底部可以调节字号。开发模式显示检查器，生产模式隐藏。

```bash
pnpm test
pnpm validate:content
pnpm build
```

生产构建为纯静态站点，导出目录为 `dist/client`，与 `.openai/hosting.json` 保持一致。无需服务器数据库或 API Key。

## 核心结构

- `src/engine`：条件、调度、概率、人物冲突与状态演进；不引用具体事件 ID。
- `src/content/packs`：早期人生、硅谷、独立随机事件包和测试扩展包。
- `src/content/registry.ts`：内容包注册、依赖解析与版本信息。
- `src/research`：来源说明与现实时间线；对分歧明确标注。
- `src/game/save.ts`：自动存档、3 个手动槽位、导入导出和兼容性校验。
- `src/ui`：小说画面、人生档案、世界线、史料与仅开发模式的检查器。

## 内容扩展

新增内容包只需要提供声明式数据并加入 Registry。事件主要由年份、标签、职业和状态筛选，不依赖固定前驱。测试包演示在已经开始的人生中加入一个事件、一个随机事件、一种结局和场景引用。开发检查器可注册并触发测试包；正式游戏默认不装载它。

同种子、同选择、同内容/人物版本可复现。随机用途互相隔离；视觉抽样不影响结果。增加内容包可能改变未来调度，不承诺不同内容版本之间仍逐事件相同。保存完整事件对象并不属于存档格式；破坏性版本变更会明确报错，当前没有臆造的自动迁移。

## 历史与范围

游戏叙事全部重新创作。参考材料来自 PBS、Queen’s、Wharton 与 Stanford eCorner；资料争议见游戏历史档案和源码来源说明。所有对话、内心、插画和假设结果都不能当成真实历史引文。人物参数只是游戏模拟。

本轮切片从童年进入，阶段结局延伸到 1999 年。完整 1971—2002 V1、PayPal、SpaceX、Tesla、AI 深度模块属于后续开发，不在当前版本中冒充完成。
