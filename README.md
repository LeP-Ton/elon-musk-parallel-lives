# 马斯克传：平行人生

一款以真实历史为骨架、让玩家与人物惯性共同改写人生的互动小说。当前为第一阶段可玩切片：15 个核心事件、3 个条件插曲、5 种阶段结局，另有独立扩展验收包。

## 本地运行

需要 Node.js >=22.13（已在 Node.js 24 验证）。项目保留 Sites 脚手架的 npm 锁文件，可使用 npm 或 pnpm 执行脚本。

```bash
npm ci
npm run dev -- --port 5187
```

访问终端给出的本机地址。普通游玩只需点击选择与“翻开下一页”；数字键 1—4 选择，Enter 继续。页面底部可以调节字号。开发模式显示检查器，生产模式隐藏。

```bash
pnpm test
pnpm validate:content
pnpm build
```

生产构建为纯静态站点，导出目录为 `dist/client`，与 `.openai/hosting.json` 保持一致。无需服务器数据库或 API Key。

## 自动播放：观众模式

点击故事上方的「自动播放」，人物会在合法选项中，根据人格倾向、压力、精力、自主冲突及种子机遇作出选择，并依次展示结果、翻页到下一场景。它使用原有的概率与结局规则，不提前挑选结局。首次直接开播会生成随机种子，之后可续播当前人生。

- 「暂停」或空格键控制播放；1×、2×、4×调节按文字量计算的阅读时长，每页至少展示两秒。
- 点击任意选择或手动翻页会立即接管并暂停；打开面板、切到后台、读档、切换内容包或发生错误也会停止自动推进。切回前台不会自行恢复。
- 「随机开播」或结局页的「再看一段随机人生」打开确认面板，可生成或输入种子。确认后替换自动存档，手动槽位保留。到达结局后停留，不无限循环覆盖人生。
- 同一种子、初始状态、选择策略及内容/人物版本可复现自动路线；暂停和倍速不重抽结果，手动接管会改变后续路线。不同种子也可能走向同一结局，不承诺每次必然不同。
- 每一步仍自动存档，旧版存档格式保持兼容；播放状态不存入存档，读取后默认暂停。当前策略版本为 `autoplay-v1`。

## GitHub 与 GitHub Pages

仓库名使用 `elon-musk-parallel-lives`。GitHub Pages 是独立的公开试玩渠道，原有 Sites 私有站点不会因此改变权限或更新版本。

```bash
npm run build:pages
```

默认以 `/elon-musk-parallel-lives` 为部署路径，输出 `dist/github-pages`。如需自定义路径，可设置 `GITHUB_PAGES_BASE_PATH`；设置为空字符串时适用于域名根目录。构建脚本会检查首页的脚本、样式、图标与插画引用，资源缺失时停止发布。

GitHub 仓库的 `Settings → Pages → Build and deployment → Source` 应选择 `GitHub Actions`。之后推送到 `main`，或手动运行「发布 GitHub Pages」工作流，会依次运行回归测试、内容校验、静态构建与发布。发布权限只授予部署任务，无需在仓库配置个人访问令牌。

源码提交、Sites 版本与 Pages 部署分别管理：GitHub 推送不会更新 Sites。Sites 与 Pages 属于不同域名，本地存档不会自动共享，可在游戏内导出存档文件后到另一站点导入。

## 核心结构

- `src/engine`：条件、调度、概率、人物冲突与状态演进；不引用具体事件 ID。
- `src/content/packs`：早期人生、硅谷、独立随机事件包和测试扩展包。
- `src/content/registry.ts`：内容包注册、依赖解析与版本信息。
- `src/research`：来源说明与现实时间线；对分歧明确标注。
- `src/game/save.ts`：自动存档、3 个手动槽位、导入导出和兼容性校验。
- `src/ui`：小说画面、人生档案、世界线、史料与仅开发模式的检查器。

## 内容扩展

新增内容包只需要提供声明式数据并加入 Registry。事件主要由年份、标签、职业和状态筛选，不依赖固定前驱。测试包演示在已经开始的人生中加入一个事件、一个随机事件、一种结局和场景引用。开发检查器可注册并触发测试包；正式游戏默认不装载它。

同种子、同选择、同内容/人物版本可复现。随机用途互相隔离；视觉抽样不影响结果。增加内容包可能改变未来调度，不承诺不同内容版本之间仍逐事件相同。保存完整事件对象并不属于存档格式；破坏性版本变更会明确报错，当前没有臆造的自动迁移。

## 历史与范围

游戏叙事全部重新创作。参考材料来自 PBS、Queen’s、Wharton 与 Stanford eCorner；资料争议见游戏历史档案和源码来源说明。所有对话、内心、插画和假设结果都不能当成真实历史引文。人物参数只是游戏模拟。

本轮切片从童年进入，阶段结局延伸到 1999 年。完整 1971—2002 V1、PayPal、SpaceX、Tesla、AI 深度模块属于后续开发，不在当前版本中冒充完成。
